# Tafaß V26 — Business + Ads

V26 finalise l'écosystème professionnel avec :
- profil Business professionnel ;
- campagnes publicitaires ;
- objectifs, budget, zone et âge d'audience ;
- impressions, clics et CTR ;
- événements analytics protégés par RPC ;
- Realtime pour les profils, campagnes et analytics ;
- RLS sans suppression des données existantes.

## Installation
Exécuter une seule fois `TAFASS_V26_BUSINESS_ADS.sql` dans Supabase SQL Editor.

Les campagnes sont créées en **brouillon**. L'activation reste manuelle depuis le tableau Business. Les métriques ne sont pas inventées : elles apparaissent uniquement après de vrais événements enregistrés côté serveur.
