# Tafaß V28.3.1 — Badges: Seen on Entry

- Navigation badges now represent NEW/UNSEEN items.
- When a user enters a section, its badge is cleared immediately.
- Notifications for that section are persisted as read.
- Opening Messages marks incoming unread messages as read.
- Notifications page marks all unread notifications as read.
- The existing V28.3 realtime notification system is preserved.
- No existing application data is deleted.
