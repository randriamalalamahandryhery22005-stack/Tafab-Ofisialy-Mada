# Tafaß — Admin Total V29

Ity version ity no manomboka amin'ny ZIP farany nomena ho fototra.

## Vita amin'ny V29
- Admin Total voaaro amin'ny `tafa_is_admin()`.
- Badge rouge ho an'ny Admin ao amin'ny Menu rehefa misy zavatra mila karakaraina.
- Comptes: total, actifs, bloqués + bloquer/réactiver.
- Monétisation: coins sy revenus créateurs.
- Retraits créateurs: lisitra + approuver/refuser.
- Paiements: lisitra + valider/refuser.
- Signalements: lisitra + marquer comme traité.
- Stats publications, commentaires, notifications.
- RPC rehetra no ampiasaina amin'ny opération admin sensitive; tsy omena client permission mivantana ny fanovana wallet/paiement.

## Installation Supabase
Ao amin'ny Supabase → SQL Editor, alefaso:
`TAFASS_ADMIN_TOTAL_V29_MONETISATION.sql`

Ataovy avy eo logout/login ao Tafaß mba havaozina ny session/permissions.

## Zava-dehibe
Ny badge rouge dia tsy isa permanent: manisa ireo **retaits pending + paiements pending + signalements pending** mila action admin.
