# Tafaß V34 — Messages Clean / Theme / Emoji

Fichiers modifiés uniquement par rapport à V33.

- `app.js`: thème de conversation appliqué réellement à l'écran, accès au thème depuis les paramètres/options, boutons premium Appel/Vidéo, vrai sélecteur de plus de 1 000 emojis insérables dans le champ de message.
