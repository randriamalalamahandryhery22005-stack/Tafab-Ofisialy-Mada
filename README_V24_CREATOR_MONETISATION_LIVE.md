# Tafaß V24 — Creator Monetisation + Live 2.0

V24 ajoute une base additive pour l'économie des créateurs et les cadeaux en direct.

## Fonctionnalités
- Portefeuille de coins et revenus créateur
- Ledger des mouvements
- Cadeaux Live atomiques via RPC Supabase
- Abonnements créateur
- Demandes de retrait (workflow admin)
- Cadeaux visibles en temps réel
- Dashboard créateur V24
- Live 2.0 : compteur, cadeaux et co-hôte préparé

## Migration
Exécuter une seule fois : `TAFASS_V24_CREATOR_MONETISATION_LIVE.sql`.

La migration ne supprime aucune donnée existante et ne rend pas le solde de coins modifiable directement par le client.
